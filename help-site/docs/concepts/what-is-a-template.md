# What Is a Template?

A template is the visual structure and set of editing options used to create a card. It determines the card's layout, the fields available in the editor, and whether the card is normally used as a front or back face.

When you choose **New**, you can start from templates including Hero Card, Monster Card, Small Artwork, Large Artwork, Rules, Hero Back, Logo Back, and Labelled Back.

The template name describes its layout and intended use; it does not limit the subject of the card. For example, Small Artwork can be used for a spell, item, ability, event, or any other card that benefits from a small illustration and a larger text area.

## Template versus card

The template is the reusable starting structure. The [card](./what-is-a-card.md) is your individual creation containing its own title, text, artwork, and settings.
