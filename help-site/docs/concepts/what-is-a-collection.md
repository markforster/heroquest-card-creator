# What Is a Collection?

A collection is a named way to group saved cards in the **Cards** library. You can use collections for a project, theme, card type, work stage, or any other grouping that helps you find related cards.

A card can remain in **All cards** while belonging to one or more collections. **Unfiled** means that a card does not belong to any named collection.

Collections can also define an export scope and filter the eligible front or back cards shown while building a deck.

## Collection versus deck

A collection is for library organization. It does not define print order, quantities, card backs, or playable structure. Use a [deck](./what-is-a-deck.md) when those relationships matter.
