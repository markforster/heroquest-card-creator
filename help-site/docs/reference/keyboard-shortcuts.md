# Keyboard Shortcuts

Keyboard shortcuts help you move between the app's main areas and reach common actions without repeatedly returning to the navigation.

The letters in the main tables are shown in uppercase for readability. Press each letter **by itself**, without Shift, Ctrl, Cmd, or Alt. The separate template-picker combination is the only modifier shortcut listed here.

## Navigate around the app

These shortcuts are available throughout the app when you are not typing or using an open dialog.

| Key | Action |
| --- | --- |
| **N** | Open the template picker to create a new card |
| **R** | Open your recent cards |
| **C** | Open Cards, your saved-card library |
| **D** | Open Decks |
| **A** | Open Assets |
| **Q** | Open Settings |
| **S** | Focus the main search box on the current screen, when one is available |

**S** works in Cards, Assets, the Decks list, and the card-source panel inside a deck. It does nothing in the Card Editor because that screen has no main browse search.

## Alternate template-picker shortcut

The New or current-card area in the navigation also shows a shortcut for opening **Choose a template**:

- On macOS, press **Cmd+Shift+Y**.
- On other platforms, the app labels it **Meta+Shift+Y**. Meta normally means the Windows key or the equivalent system key on your keyboard.

Bare **N** opens the same template picker and is the simpler cross-platform choice.

## Card Editor shortcuts

These keys work while creating or editing a card.

| Key | Action |
| --- | --- |
| **V** | Switch between **Standard (2D preview)** and **Interactive (3D preview)** |
| **M** | Switch the Interactive preview between **Pan** and **Rotate** |

**M** only works while Interactive preview is active. It does nothing while Standard preview is selected.

## Deck export shortcuts

These keys work while editing an individual deck.

| Key | Action |
| --- | --- |
| **E** | Open or close the deck's **Export** menu |
| **I** | Choose image export while the Export menu is open |
| **P** | Choose PDF export while the Export menu is open |

The deck must contain exportable sets before its Export control becomes available. **I** and **P** do nothing while the menu is closed, which keeps the keyboard action aligned with the choices visible on screen.

## When shortcuts do not run

You can type normally without triggering navigation. These shortcuts are ignored while your cursor is in:

- a text or number field
- a multiline text area
- a dropdown or select control
- another editable text area

App-wide shortcuts also pause while windows such as Recent, Settings, or the template picker are open. Close the current window before using another navigation shortcut.

For screen-specific causes and a recovery checklist, see [Fix Keyboard Shortcut Problems](../troubleshooting/fix-keyboard-shortcut-problems.md).
